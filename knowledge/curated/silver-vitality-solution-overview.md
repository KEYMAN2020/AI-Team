# 银发活力平台 方案说明

> 面向中老年人的线下活动社交平台，帮他们走出家门、认识朋友、丰富退休生活。

---

## 一、平台上有谁

三种角色：

| 角色 | 做什么 |
|------|--------|
| 普通用户 | 看活动 → 报名 → 签到 → 参加 |
| 队长 | 发布活动 → 现场组织 → 签到核销 → 报备 |
| 平台管理员 | 审核活动 → 审核队长 → 查看运营数据 |

---

## 二、方案设计对比

### 2.1 积分体系

| 对比项 | 初版方案 | 当前方案 |
|--------|---------|---------|
| 名称 | 活力积分 | 活力值 |
| 获取方式 | 签到得、邀请得 | 仅参加活动获得 |
| 会不会减少 | 会（参加活动消耗） | 不会（只增不减） |
| 用途 | 兑换礼品 | 不兑换，仅作为活跃度标识 |
| 邀请奖励 | 有（20分/人，月限5次） | 没有 |

**简单说**：初版的积分本质是"赚了花"的类货币，有合规风险。当前的活力值只是你活跃度的记录，不是钱，不消耗、不兑换。

### 2.2 角色层级

| 对比项 | 初版方案 | 当前方案 |
|--------|---------|---------|
| 用户端 | 小程序 | 小程序 |
| 队长 | 有 | 有 |
| 城市运营官 | 砍掉了（平台自己做） | 砍掉了（平台自己做） |
| 社区/街道 | 没有 | **有（作为合作方接入系统）** |

**简单说**：初版把运营官砍掉后，运营工作全部压给平台。当前方案把社区/街道作为合作角色纳入系统——他们提供场地和宣传，平台提供软件服务。

### 2.3 活动安全

| 对比项 | 初版方案 | 当前方案 |
|--------|---------|---------|
| 活动分级 | 绿/黄/红三级，红色直接砍掉 | 绿/黄两级，**保留红色但加限制** |
| 紧急联系人 | 填写 + 短信确认 | 填写 + 短信确认 + 活动前自动提醒 |
| 场地确认 | 队长拍照上传 | 拍照上传 + 系统判断是否合规 |
| 健康声明 | 勾选 + 队长口头确认 | 系统自动弹出确认，无需队长操作 |
| 保险 | 1元/人/天 | 同上 |
| 天气预警 | 没有 | **有（自动检测天气，黄色活动自动降级）** |

**简单说**：当前方案的安全更智能化——系统自动做天气检测、自动提醒紧急联系人、自动做健康确认，减少队长的手动操作。

### 2.4 队长端

| 对比项 | 初版方案 | 当前方案 |
|--------|---------|---------|
| 申请条件 | 年龄≤75岁 + 线上培训 | 同上 |
| 发布活动 | 选类型→填信息→上传安全确认书 | 选类型→填信息→**系统自动校验后发布** |
| 签到方式 | 队长扫码签到 | 同上 |
| 活动报告 | 手动填写 | **模板化填写，减少打字** |

### 2.5 MVP 功能范围

| 功能 | 初版方案 | 当前方案 |
|------|---------|---------|
| 活动列表 | ✅ | ✅ |
| 报名/签到 | ✅ | ✅ |
| 个人中心 | ✅ | ✅ |
| 队长发布活动 | ✅ | ✅ |
| 活动审核 | ✅ | ✅ |
| 积分商城 | ✅（MVP包含） | **❌（不做）** |
| 私信聊天 | ❌ | ❌ |
| 评价系统 | ❌ | ❌ |
| 付费功能 | ❌ | ❌ |
| 天气预警 | ❌ | **✅** |
| 社区/街道管理后台 | ❌ | **✅** |

## 三、一句话

> 帮中老年人走出家门参加线下活动、认识新朋友，安全有保障，队长好组织，平台好管理。
