# 银发活力平台 设计理念

> 银发活力平台的设计从合规分析出发，历经多轮迭代，最终形成一套既安全可行又能真正满足银发群体需求的方案。

## 二、核心设计哲学 — 三条铁律

```mermaid
mindmap
  root(("设计哲学"))
    铁律一：合规是约束条件，不是功能开关
      积分不可提现不可转账 → 但不是改成"弱激励"
      层级扁平 → 但不是去掉中间层 = 平台自己做
      活动安全 → 用设计保障，不是用流程堆砌
    铁律二：银发群体的真实需求才是产品起点
      他们需要的是"走出家门"的理由
      不是积分、不是等级、不是虚拟激励
      产品本质：线下社交活动的组织工具
    铁律三：运营和产品是一体的
      地推不是拉新手段，是产品的一部分
      队长不是平台员工，是社区的灵魂人物
      活动质量 = 留存，不需要复杂的会员体系
```

## 四、积分体系 — 从"激励"到"仪式感"

```mermaid
flowchart LR
    subgraph 旧思维["旧方案积分逻辑"]
        A["参加活动 → 赚豆/币"]
        B["攒够豆 → 兑换商品"]
        C["问题：类虚拟币合规风险"]
    end

    subgraph 新思维["当前方案积分逻辑"]
        D["参加活动 → 获得活力值"]
        E["活力值 = 你的活跃度"]
        F["不是货币，是身份标签"]
        G["用途：活动分级准入\n（活跃用户优先报名热门活动）"]
    end

    旧思维 -->|"合规重构"| 新思维
```

### 积分设计要点

| 维度 | 合规版 | 当前方案（更好） |
|------|--------|-----------------|
| 名称 | 活力积分 | **活力值**（彻底去"币/积分"化） |
| 获取 | 签到得20、邀请得20 | **仅通过参加活动获得**（参加1次=10活力值） |
| 消耗 | 参加活动消耗15-20 | **不消耗**（活力值是累计的，不是消耗品） |
| 用途 | 兑换礼品 | **活动分级准入 + 荣誉标识** |
| 邀请奖励 | 一次性20积分，月限5次 | **不设邀请奖励**（不做裂变，做口碑） |
| 充值 | 始终不做 | 始终不做 |
| 本质 | 弱化版的虚拟币 | **不是货币，是活跃度指标** |

> **核心转变**：合规版只是把"虚拟币"改名叫"积分"，本质上还是"赚-花"的货币逻辑。当前方案彻底跳出这个框架——活力值不是钱，是你参与了多少活动的**证明**。

## 五、活动安全 — 三层防护 vs 流程堆砌

```mermaid
flowchart TB
    subgraph 活动前["活动前 - 预防层"]
        S1["活动分级（绿/黄/红三级）"]
        S2["场地安全确认（队长拍照上传）"]
        S3["天气预警（自动检测）"]
    end

    subgraph 活动中["活动中 - 保障层"]
        S4["签到确认（点名）"]
        S5["健康状态口头确认"]
        S6["紧急联系人可追踪"]
    end

    subgraph 活动后["活动后 - 追溯层"]
        S7["活动报告（队长填写）"]
        S8["异常上报"]
        S9["保险备案"]
    end

    活动前 --> 活动中 --> 活动后
```

### 安全设计的三个原则

1. **不做"填表式安全"** — 紧急联系人不只是填个号码，而是系统发短信确认+活动前自动提醒
2. **活动分级是动态的** — 同一类型的活动在不同天气/场地条件下自动升降级
3. **安全是体验的一部分** — 不是弹窗、不是勾选框，而是让用户感觉"被照顾到了"

## 六、冷启动 — 街道模式 vs 地推模式

```mermaid
flowchart TB
    subgraph 地推模式["传统地推"]
        A1["扫码送鸡蛋"]
        A2["单次转化率低"]
        A3["用户信任度低"]
        A4["留存差"]
    end

    subgraph 街道模式["街道合作"]
        B1["与社区/街道合作"]
        B2["街道提供场地和宣传"]
        B3["退休党支部 / 老年大学"]
        B4["天然信任 + 精准人群"]
        B5["高出证率 + 高留存"]
    end

    A1 --> A2 --> A3 --> A4
    B1 --> B2 --> B3 --> B4 --> B5
```

| 维度 | 传统地推 | 街道合作模式 |
|------|---------|-------------|
| 信任基础 | 低（陌生地推） | **高（街道公信力背书）** |
| 用户精准度 | 低（扫街） | **高（退休人群集中）** |
| 单次获客成本 | 5-10元（礼品+人力） | **接近于 0（街道合作）** |
| 留存率 | <20% | **> 60%（熟人社区）** |
| 规模化路径 | 铺更多街道 | **复制街道合作模式** |
