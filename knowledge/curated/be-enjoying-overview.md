# BeEnjoyIng — 项目概述（供 AI 开发团队使用）

## 一句话
面向 40-70 岁中老年人的线下活动社交平台，帮他们走出家门、参加活动、认识朋友。

## 技术栈
| 层 | 技术 | 说明 |
|---|------|------|
| 后端 | Python Flask | REST API，RESTful 风格 |
| 数据库 | MySQL 8.0 | 已部署在 localhost:3306 |
| 数据库名 | silver_vitality | 37 张表已建好并导入 |
| 前端 | 微信小程序 | （ai-team 不开发前端，只出 API） |
| 部署 | 腾讯云 CVM 上海 | 124.220.16.67 |

## API 规格
- 所有 API 遵循统一响应格式：{code: 0, data: {...}, message: ok}
- 认证方式：JWT token（access_token + refresh_token）
- 认证流程：手机号 + 验证码登录（无密码注册步骤）
- 接口路径前缀：/api/v1/

## API 清单（74 个接口，9 大模块）
### 一、认证模块（5）
1. POST /api/v1/auth/send-code — 发送验证码
2. POST /api/v1/auth/login — 手机号+验证码登录（新用户自动注册）
3. POST /api/v1/auth/wx-login — 微信授权登录
4. POST /api/v1/auth/logout — 退出登录
5. POST /api/v1/auth/refresh — 刷新 Token

### 二、用户模块（8）
6-13：获取/更新资料、查看他人、紧急联系人、健康声明、好友、注销、设置

### 三、活动模块（16）
14-29：活动列表、分类、详情、报名、取消、收藏、评价、相册、候补、安全信息、推荐

### 四、消息模块（7）
30-36：会话列表、消息历史、发送消息、公告、已读、未读数、上传图片

### 五、队长工具（11）
37-47：申请认证、工作台、发布/编辑/取消活动、签到、二维码、活动报告

### 六、安全模块（5）
48-52：SOS、活动前安全确认、健康确认、举报、举报记录

### 七、通知模块（3）
53-55：通知列表、标记已读、全部已读

### 八、管理后台（12）
56-67：看板、审核活动/队长、用户管理、举报处理、安全事件

### 九、通用模块（7）
68-74：上传图片、全局配置、静态资源、健康检查、城市列表、热搜词、用户反馈

## 当前开发阶段

- 按接口逐个开发：完成一个 → 提交到 dev 分支 → 用户 review → 通过后下一个
