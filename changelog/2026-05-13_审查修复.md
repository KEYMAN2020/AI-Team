# 2026-05-13 角色重组代码审查修复

## 发现的问题（15个）

### HIGH（2个）— 已修复
1. **别名解析不完整**：`get_role_config`/`get_role_tools`/`get_role_kb_sections`/`get_role_resource_cats` 四个函数不支持别名（如 fe→frontend）。导致 `get_role_timeout("fe")` 返回默认超时而非 300s。→ 四个函数均添加 `resolve_role(role) or role`
2. **`_approval` KeyError**：message_bus 的 ALL_ROLES 不包含 `_approval`，但 runner.py 的 VALID_ROLES 包含。如果 LLM 生成 sub_request 目标是 `_approval`，bus.post 会 KeyError 崩溃。→ ALL_ROLES 始终追加 `_approval`

5. TOCTOU 竞态 — 理论风险，不修（现有 try/except 已兜底）
6. **注释粘连**：model_adapter.py 行100 pass 后注释与下一段头连一起 → 加换行
7. **0 角色误报通过**：health_check 在无任何角色时返回通过 → 加 `if not roles: return False`

11. alias 无法用于 message_bus.post → 实战中不会发生（DAG 用 canonical 名）
12. **模块变量泄漏**：tools/knowledge/resource 三模块 overlay import 后变量残留 → 添加 `del`
