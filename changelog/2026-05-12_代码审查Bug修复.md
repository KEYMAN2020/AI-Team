## 修复清单

### P0 — 严重 Bug

#### 1. model_adapter.py 缺少 `get_tools_for_role` 导入
- **问题**: `_call_deepseek`、`_call_claude`、`_call_openai` 三处调用 `get_tools_for_role(role)` 但从未导入 → NameError 运行时崩溃
- **修复**: 文件顶部添加 `from tools_registry import get_tools_for_role, get_tool_names_for_role`
- **影响**: 工具功能从未实际生效，角色拿不到 tools 列表

#### 2. `_tester_found_bugs` 关键词误判
- **问题**: Tester 输出 "测试通过，无 error，无 bug" → 命中 "error"+"bug" → 误判有 Bug → 不必要的 QA→DBG 循环
- **修复**: 改为正负双向关键词：正向命中（bug/fail/缺陷等）**且** 否定词未命中（测试通过/全部通过/successfully等）才判定有Bug
- **文件**: `runner.py:_tester_found_bugs()`

#### 3. 快照文件名解析对含下划线的 task_id 有 bug
- **问题**: `DBG_1`、`RETEST_2`、`D_final` 含下划线 → `split("_")[1]` 只取到 "DBG"/"RETEST"/"D"
- **修复**: 从右往左找日期部分（8位数字 YYYYMMDD），之前的部分全部作为 task_id 拼接
- **文件**: `runner.py:_find_completed_tasks_from_snapshots()`

### P1 — 设计缺陷

#### 4. 知识库和资源库上下文从未注入
- **问题**: `build_kb_context(role)` 和 `build_library_context(role, task)` 定义了但从未在角色调用时注入
- **修复**: `runner.py:_call_agent_async()` 中，在 `build_context()` 后追加知识库和技术储备内容

#### 5. OpenAI ROLE_CONFIGS 缺少 4 个角色
- **问题**: openai provider 缺 product/ux/dba/reviewer → ACTIVE_PROVIDER="openai" 时 KeyError
- **修复**: 补全 4 个角色（均用 gpt-4o，按职责设 temperature）
- **文件**: `model_adapter.py:ROLE_CONFIGS["openai"]`

#### 6. Gemini ROLE_CONFIGS 同样缺 4 个角色
- **修复**: 补全 product/ux/dba/reviewer
- **文件**: `model_adapter.py:ROLE_CONFIGS["gemini"]`

#### 7. o1 模型参数不兼容
- **问题**: o1 不支持 `temperature`（必须传）、`max_tokens`（应改为 `max_completion_tokens`）、tools/function calling
- **修复**: o1 分支使用 `max_completion_tokens=4096`，不传 temperature 和 tools
- **文件**: `model_adapter.py:_call_openai()`
