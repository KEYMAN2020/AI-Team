## P1: Gemini 完全没有工具支持

**文件**: `references/model_adapter.py`

**严重性**: 所有使用 Gemini 的角色（前端/后端/测试等）无法调用任何工具。
`_call_gemini()` 直接 `model.generate_content(user)` 没有传 tools 参数，
没有 function calling 循环处理。Gemini 用户在深水区游泳。

**修复**:
- 新增 `_to_gemini_tools()` — 将内部工具定义转为 Gemini `Tool(FunctionDeclaration)` 格式
- 新增 `_run_tool_loop_gemini()` — 多轮 functionCall/functionResponse 循环，最多 5 轮
- `_call_gemini()` 现在正确传递 tools 并走 tool loop

**影响范围**: Gemini provider 的所有角色。

---

## P2: `/bin/bash` 硬编码 — Windows 兼容

**文件**: `references/tools_registry.py`

**问题**: `_exec_code_run` 中 bash 执行命令写死 `/bin/bash`，Windows 不存在该路径。

**修复**: 改为 `bash`（从 PATH 查找）。
