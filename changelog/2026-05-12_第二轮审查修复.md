## P1 严重修复

### 1. Tools 系统从空壳变为真正可用
**文件**: `references/model_adapter.py`
**问题**: Tools 格式转换函数直接返回原值、Tool Loop 从未实现多轮、7 个工具从未真正工作过。
**修复**:
- `_to_openai_tools`: 加 `{"type":"function", "function":{...}}` 包装
- `_to_anthropic_tools`: `parameters` → `input_schema` 重命名
- `_run_tool_loop_openai`: 真正实现多轮 tool_calls → execute_tool → tool_result 循环（max 5 轮）
- `_run_tool_loop_claude`: 实现 tool_use → execute_tool → tool_result 循环（max 5 轮）
- 补全 `execute_tool` 导入

### 2. message_bus 死代码清除 + 锁统一
**文件**: `references/message_bus.py`
**问题**: `_make_msg` 中定义了 async `_inner` 从未调用；每次调用都 import threading + 创建新 Lock；混用 threading.Lock 和 asyncio.Lock。
**修复**:
- 删除 `_inner` 死代码
- `_make_msg` 改为 async，统一使用 `self._lock`（asyncio.Lock）
- `post`/`broadcast`/`reply` 改为 `await self._make_msg(...)`
