# 2026-05-13 角色单一来源重构（role_registry）完成

## 背景

之前加一个角色需要改 8 个文件（model_adapter.py / tools_registry.py / knowledge_base.py / resource_library.py / message_bus.py / runner.py / health_check.py / _ROLE_FILE_MAP），极易遗漏。

## 改造内容

### 核心：role_registry.py
- 扫描 `roles/*/config.yaml` 自动发现和注册所有角色
- 提供统一 API：`get_all_roles()`, `get_role_config()`, `get_role_tools()`, `get_role_kb_sections()`, `get_role_resource_cats()`, `get_role_prompt()`, `get_role_file_map()`, `resolve_role()`
- 线程安全缓存，支持别名解析

### 角色目录：roles/<name>/
- 11 个角色目录，每个包含：
  - `config.yaml` — 角色配置（模型参数、工具、知识库章节、资源分类）
  - `prompt.md` — 系统提示词
- 配置文件从 model_adapter 硬编码 ROLE_CONFIGS、tools_registry ROLE_TOOLS、knowledge_base ROLE_KB_SECTIONS、resource_library CATEGORY_MAP 中提取

### 消费模块更新（所有模块保留硬编码 fallback）

| 模块 | 改动 |
|------|------|
| model_adapter.py | ROLE_CONFIGS 从 role_registry 获取；_ROLE_FILE_MAP → get_role_file_map()；load_system_prompt() → get_role_prompt()；get_role_timeout() → registry |
| tools_registry.py | ROLE_TOOLS 保留 fallback + registry 叠加 |
| knowledge_base.py | ROLE_KB_SECTIONS 保留 fallback + registry 叠加 |
| resource_library.py | CATEGORY_MAP 保留 fallback + registry 叠加 |
| message_bus.py | ALL_ROLES 保留 fallback + registry 叠加 |
| runner.py | VALID_ROLES 从 role_registry.get_all_roles() 获取 |
| health_check.py | _check_role_files() 改用 role_registry |

### 配置文件清理
- config/workflow.yaml: valid_roles 改注释说明（默认从 registry 自动发现）
- config/roles.yaml: 更新注释说明此为覆盖层

## 效果

**加新角色现在只需要**：
1. 创建 `roles/<new_role>/` 目录
2. 添加 `config.yaml` + `prompt.md`
3. 重启服务器即可

不再需要修改任何 .py 文件。
